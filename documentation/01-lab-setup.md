# Linux Server Hardening Lab - Lab Setup

## Overview

This project is a hands-on cybersecurity home lab designed to demonstrate the process of securing and hardening a Linux server.

The lab will focus on reducing the server's attack surface, implementing security controls, monitoring system activity, and performing vulnerability assessments.

## Objectives

- Deploy a Linux server in a virtualized environment
- Establish a baseline configuration before hardening
- Apply Linux security best practices
- Harden SSH access
- Configure a host-based firewall
- Implement intrusion prevention with Fail2Ban
- Configure system logging and auditing
- Configure automatic security updates
- Perform vulnerability scanning
- Document security improvements and findings

## Lab Environment

The lab will use virtual machines to create an isolated environment for testing.

### Planned Components

| Component | Purpose |
|---|---|
| Ubuntu Server | Target system to be hardened |
| Kali Linux | Security testing and assessment |
| VirtualBox | Virtualization platform |
| GitHub | Project documentation and version control |
